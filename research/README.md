# 발음 연구

운영 코드와 분리한 한국어 아동 발음 모델 조사 자료입니다. 현재 폴더에는 실험 보고서가 있으며 학습 모델이나 원본 데이터는 포함되지 않습니다.

- `pronunciation/README.md`: 연구 범위와 데이터 취급 원칙.
- `pronunciation/reports/pronunciation_final.md`: 최종 결론.
- `pronunciation/reports/pronunciation_v1.md`: 초기 조사 기록.

`data/`, `cache/`, `checkpoints/`, `outputs/`는 Git 제외 경로입니다. 연구용 의존성을 운영 백엔드의 `requirements.txt`에 넣거나 연구 결과를 검증된 치료 효과로 표현하지 마세요.
