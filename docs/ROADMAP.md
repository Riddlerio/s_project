# 개발 로드맵

2026-10-10 기준. 확인한 main은 PR #33 병합 커밋 575f8b2이다. 이 문서는 현재 상태와 다음 작업만 다룬다. 완료 과정과 당시 지시는 [작업 기록](WORK_HISTORY.md)에, 변경 전에 지킬 경계는 [동결 계약](audit/FROZEN_CORE_CONTRACT.md)에 있다. 사용자는 시연이 아직 예정 또는 연기된 상태라고 확인했으며, 새 일정은 이 문서에 기록되지 않았다.

## 지금 구현된 흐름

아동은 두두 대화 → 대구대 건너기(한 판 5라운드 × 2줄, 같은 회기에서 최대 3판) → 피드백 없는 새 낱말 확인 → 마무리 순서로 진행한다. 치료사는 회기의 관찰을 확인·교정하고 연습과 새 낱말 확인을 분리해 본다. 다음 회기 계획의 초안·승인은 구현됐지만, 승인한 계획이 아동 게임을 자동으로 구동하는 연결은 아직 없다.

완료된 Codex 번호 작업 1~6번은 PR #22·#24·#26·#32에 반영됐다. [완료 기록](WORK_HISTORY.md)을 참고한다.

## 우선순위

1. **실제 기기와 사람 검토:** 최신 main으로 아이폰 Safari·마이크·스피커에서 아동부터 치료사까지 전체 흐름을 확인한다. 10/6 사용자의 제한된 아이폰 발음 시험은 있었지만 최신 버전의 전체 리허설 기록은 없다. 새 낱말 확인의 중립 진행, 자동 추정 이유, /ㅅ/ 기준값을 치료사와 함께 확인한다. [휴대폰 검사와 확인 목록](handoff/DEMO_RUNSHEET_2026-10-05.md)
2. **선택적 OpenAI 경로 재검증:** 10/7 짧은 실제 8턴 시험은 있었으나 당시 치료사 요약은 600토큰 한도에서 잘렸다. 최신 코드·사용할 키와 모델로 대화, 요약 길이, 지연, 실패 시 대체 응답을 다시 확인한다. [당시 수치](WORK_HISTORY.md)
3. **시연과 운영 준비:** 시연 전에 현장 HTTPS·네트워크·마이크 권한·백업 영상과 버전을 확인한다. 공개·포스터 전에는 앱 이름의 중복 가능성과 자산 사용 범위를 확인한다([결정 기록](DECISIONS.md)). 운영 전에는 브랜치 보호와 DB 마이그레이션·백업·성능 점검을 따로 마친다.

## 후속 기능의 경계

- 현재 건너기 음향 기준은 어두 /ㅅ/용 임시 제품 규칙이다. /ㅈ/에는 별도 실측·판정 규칙이 필요하고, /ㄹ/은 현재 마찰음 방식으로 평가할 수 없다. 새로운 소리와 장애 유형을 단순 설정 변경만으로 제공하지 않는다.
- 다른 게임 4종의 장면 확장과 집·지도·보상 재디자인은 시연 흐름과 분리해 검토한다. 당시 연출 구상은 [이전 로드맵](https://github.com/Riddlerio/s_project/blob/575f8b27deac6dd1c1d72d9a75f793360ccd61a1/docs/ROADMAP.md)에 남아 있다.
- 원음 청취 기능은 보호자 동의, 보존 기간, 삭제 방법을 먼저 정해야 한다. 현재 앱 서버는 원음 파일을 저장하지 않는다.
