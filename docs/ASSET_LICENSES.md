# 에셋·라이선스 표 (Phase 3, 2026-10-05)

앱과 저장소에 들어 있는 그림·3D·음성·글꼴과 외부 서비스의 출처와 사용 조건을 한곳에 모았다. 법률 검토가 아니다. 사용자가 받은 허락과 서비스 약관을 기준으로 정리했다.

> **중요: 이 저장소는 공개(PUBLIC)다.** 아래 대학 자료(두두 원화로 만든 입력 이미지, 3D 모델, 공식 흉장)를 누구나 내려받을 수 있다. 대학 사용 허락에 **공개 저장소 게시·3D 변환·데모 배포**가 들어 있는지 사용자가 확인해야 한다(서면 허락 문서 미확보). 들어 있지 않으면 저장소를 비공개로 바꾸거나 해당 파일을 빼야 한다.

## 2-1. 생성 그림(2026-10-05)

| 에셋 | 위치 | 만든 방법 | 조건 | 남은 확인 |
|---|---|---|---|---|
| '대구대 건너기' 카드 그림 | `public/assets/art/crossing_card.webp`(1024×1024) | Meshy 이미지 생성(Nano Banana Pro). 사용자 Meshy 유료 계정의 크레딧으로 만들었고, 사용자가 직접 로그인했다. 프롬프트: 횡단보도가 대학 정문(긴 보·줄무늬 원통 탑·어두운 판이 있는 기둥·붉은 벽돌 광장)으로 이어지고 음표가 떠 있는 3D 만화풍. 사람·동물·캐릭터·글자는 넣지 않았다 | Meshy 약관(유료 플랜 생성물)과 기반 모델 약관을 따른다. 구글 이미지 모델 출력에는 보이지 않는 워터마크(SynthID)가 들어갈 수 있다. 대구대 정문 사진은 넣지 않고 글로만 묘사했다 | 상업적으로 쓰기 전에 Meshy·모델 약관 확인 |
| 하늘·언덕 배경 | `public/assets/art/sky_hills.webp`(1376×768) | 같은 방법. 하늘·구름·초록 언덕·나무·꽃, 오른쪽 위에 유리 돔 대학 건물이 있는 떠 있는 섬 | 같음 | 같음 |

- **크레딧:** 그림 10장을 만들어 72크레딧을 썼다(1,225 → 1,153).
  - 카드 4장 36크레딧
  - 배경 2장 18크레딧 + 이음매가 생겨 다시 만든 2장 18크레딧
- **고른 것:** 앱에는 카드 1장과 배경 1장만 넣었다. 나머지는 Meshy 계정에만 있다.
- **두두를 그리지 않은 이유:** 두두는 공식 캐릭터라 AI가 그리면 원화와 달라질 수 있다. 화면의 두두는 3D 모델(GLB)이다.

| 이모지(🚸 🐾 🚦 등) | 기기의 기본 이모지 글꼴로 보인다 |
| 디자인 토큰 | `shared/design-tokens.json`. 직접 정한 값이다 |

## 4. 외부 서비스·라이브러리

| 대상 | 쓰는 곳 | 조건·주의 |
|---|---|---|
| 브라우저 음성 인식(Web Speech API) | 실제 음성 모드의 대화·일부 게임 | 브라우저 제공업체로 음성이 전송될 수 있다(README 고지) |
| 브라우저 음성 합성(speechSynthesis) | 음성 파일이 없는 말 | Edge 온라인 음성은 인터넷이 필요하다 |
| OpenAI(선택) | 서버 설정으로 켰을 때의 대화 문장·치료사 요약 | 기본은 꺼져 있다. 키는 서버에만 둔다 |
| npm·pip 패키지(React, three, FastAPI 등) | 앱 전체 | 각 패키지의 라이선스를 따른다. 패키지별 라이선스 목록은 아직 뽑지 않았다(미실행) |

## 5. 바꿀 때의 규칙

- 대학 자료(캐릭터·흉장·교명·교훈·정문)를 새로 넣거나 쓰임을 넓히면 이 표를 고치고 허락 범위를 확인한다.
- 두두 음성 문장을 더하면 같은 VOLI 계정·보이스로 만들고, 플랜 조건(무료면 비상업·출처 표기)을 지킨다.
- 출처를 모르는 그림·소리·글꼴 파일은 넣지 않는다.
