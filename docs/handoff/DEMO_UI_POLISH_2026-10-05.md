# 시연 화면 다듬기: 참고 디자인과 인기·인디 게임 원칙 (2026-10-05, Claude 담당분)

## 사용자 요청과 결정

사용자가 2026-10-05에 요청한 것은 다음과 같다.
- 참고 이미지처럼 만들기: 하늘 배경 위에 세로로 큰 두두, 그림이 있는 게임 카드, 큰 시작 버튼.

분담: 아동 화면은 Claude가, 백엔드와 치료사 화면은 Codex가 맡는다(`RHYTHM_CROSSING_2026-10-05.md`).

## 1. 찾아본 원칙과 적용

| 출처 | 원칙 | 적용 |
|---|---|---|
| 듀오링고([디자인 분석](https://blakecrosley.com/guides/design/duolingo), [모양 언어](https://blog.duolingo.com/shape-language-duolingos-art-style/)) | 버튼 아래에 같은 색의 진한 '턱'이 있어 누르면 쑥 들어간다. 모서리는 넉넉히 둥글다(버튼 12px 안팎, 카드 16~20px, 칩은 완전한 원) | 시연 화면의 모든 버튼을 3D 버튼으로 바꿨다. 아래 5px 턱이 있고, 누르면 4px 내려간다. 게임 카드도 누르면 들어간다 |
| 동물의 숲([글꼴 분석](https://madegooddesigns.com/animal-crossing-font/)) | 날카로운 모서리 없이 모두 둥글다. 통통하고 둥근 글꼴이 말풍선과 같은 손으로 그린 듯 어울려 포근함을 준다 | 둥근 글꼴 **나눔스퀘어라운드**(OFL)를 아동 화면 전체에 쓴다. 말풍선에는 흰 고리를 두르고 모서리를 더 둥글게 했다 |
| 브롤스타즈([디자인 비평](https://ixd.prattsi.org/2025/02/design-critique-brawl-stars/)) | 가장 중요한 '플레이' 버튼을 크고 밝게 둔다. 대비를 강하게 하고 아이콘을 크게 한다 | '대화 시작'은 크고 밝은 연두 버튼(높이 62px)이다. 게임 카드 화살표는 ▶ 재생 표시로, '리듬게임'은 금색 스티커로 했다 |
| 아동 UX([원칙 정리](https://www.ramotion.com/blog/ux-design-for-kids/)), 토카보카·사고미니 | 선택지는 적게, 움직임은 차분하게, 누르는 곳은 크게 | 화면마다 할 일은 하나다(대화 → 카드). 효과는 한 번만 나고 반복하지 않는다. 버튼은 모두 44px 이상이고 주요 버튼은 52~62px이다 |

**제목:** 흰 테두리를 두른 스티커 글씨로 했다. 그림 배경 위에서도 또렷하다.

## 2. 그림(Meshy 이미지 생성)

- 카드 그림과 배경 그림은 Meshy 이미지 생성(Nano Banana Pro)으로 만들었다.
  - **카드 그림:** 정문·횡단보도·음표
  - **배경 그림:** 하늘·구름·언덕, 떠 있는 유리 돔 대학 섬
- 사용자 계정 크레딧 72를 썼다. 출처와 조건은 `docs/ASSET_LICENSES.md` 2-1절에 있다.
- 처음 만든 배경에는 오른쪽에 잘린 이음매가 있었다. "오른쪽은 카드 자리로 비워 둬"라는 지시 때문으로 보여서, 그 지시를 빼고 다시 만들었다.
- **3D 나무:** 원뿔 대신 생성 그림의 둥근 나무 모양에 맞춘 코드 나무와 덤불을 쓴다. 이것으로 충분해서 Meshy 3D는 쓰지 않았다.
- **3D 정문:** 사진 기반 코드 모형 그대로다.

## 3. 화면 구성

| 화면 | 바뀐 것 |
|---|---|
| 로그인 | 하늘 그림 배경, 손 흔드는 3D 두두(데스크톱), 3D 버튼, 둥근 글꼴 |
| 두두와 대화 | **허브 구성:** 왼쪽에 세로로 선 큰 두두, 오른쪽에 말풍선(그림 단서 포함), 상태, 입력, 게임 카드. 두두가 게임을 권하면 카드가 빛나고, 휴대폰에서는 카드가 보이게 저절로 내려간다 |
| 대구대 건너기 | 하늘 그림 배경, 3D 장면 하늘을 같은 색으로, 둥근 나무·덤불, '하나·둘·셋·넷'은 동그라미 안, 3D 버튼 |
| 마무리 | 허브 구성(큰 두두, 말풍선, 오늘 연습한 말 카드, '처음으로' 큰 버튼) |

## 4. 휴대폰 우선(최종 시연은 휴대폰)

- **대화 화면(390×844 기준)**
  - 두두 무대는 화면 높이의 38%다(최소 270px).
  - 말풍선 글씨는 1.15rem, 그림 단서는 46px, 카드 그림 높이는 132px이다.
  - 첫 화면에 두두·말풍선·입력이 다 들어온다.
  - 카드는 두두가 권할 때 저절로 화면에 들어온다(움직임 줄이기 설정이면 바로 이동).
- **건너기 화면:** 둥근 글꼴 HUD와 3D 쉬기 버튼, 박 표시를 무대 아래에 둔다.
- **리허설:** 실제 아이폰은 리허설 때 HTTPS 주소(`https://192.168.219.116:5183`)로 확인한다. 리허설은 사용자가 시작을 알린다.
