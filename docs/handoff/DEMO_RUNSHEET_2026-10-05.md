# 시연 진행표 (초안, 2026-10-05)

> 상태: **초안(서버 연결 확인 2026-10-05).** 이어받은 서버로 시연 계정 로그인 → 대화 → 건너기 10줄(서버 판정) → 마무리 → 치료사 기록까지 자동 흐름으로 확인했다. 실제 마이크·휴대폰 리허설은 D4~D5(10/8~9)에 한다. 흐름과 근거는 [DEMO_FLOW_PLAN_2026-10-05.md](DEMO_FLOW_PLAN_2026-10-05.md)에 있다.

## 1. 시연 전 점검 (약 10분)

- **브라우저:** Microsoft Edge 최신판.
- **두두 목소리:** 게임·마무리·첫 인사는 VOLI '하람' 소년 음성 파일로 말한다([DUDU_VOICE_VOLI_2026-10-05.md](DUDU_VOICE_VOLI_2026-10-05.md)).
  - 파일이 없는 말(대화 중 두두의 질문 등)은 브라우저 음성으로 말한다.
  - 브라우저 음성은 Edge 온라인 남성 음성(InJoon → Hyunsu)이고 인터넷이 필요하다.
  - 화면 아래의 VOLI 출처 문구는 무료 플랜 조건이므로 지우지 않는다.
- **마이크:** 주소창 자물쇠에서 마이크를 허용한다. 입과 마이크 사이는 20~30cm, 조용한 곳에서 한다.
- **소리:** 두두가 말할 때는 마이크가 쉬지만, 스피커를 너무 크게 하면 효과음이 다음 말에 섞일 수 있다. 중간 음량으로 맞춘다.
- **점검 화면:** `/voice-mic-check.html`에서 두두 목소리를 고르고, '사' 5번·'스' 5번을 말해 본다. '결과 복사' 값은 판정 기준을 맞출 때 쓴다.
- **시연 계정(리허설 DB 전용):** 아동 `DEMO-CROSSING` / 치료사 `demo-showcase`, 비밀번호는 둘 다 `speechhero`다. 아동 별명은 '두두친구'로, 두두가 "두두친구야", "역시 두두친구야!"라고 부른다.
- **리허설 DB 만들기와 오늘 기록 지우기:** `SEED_DEMO_DATA=true`인 상태에서 아래를 실행한다. 실제 DB에는 실행을 거부한다.
  ```powershell
  backend\.venv\Scripts\python.exe backend\scripts\demo_rehearsal.py provision --database <새 파일 경로>.db    # 처음 한 번
  backend\.venv\Scripts\python.exe backend\scripts\demo_rehearsal.py reset-today --include-mic --database <같은 경로>.db   # 리허설 사이마다(마이크 회기 포함)
  ```
  서버는 `DATABASE_URL=sqlite:///<같은 경로>.db`, `SEED_DEMO_DATA=true`로 띄운다. 초기화 전에는 진행 중인 리허설을 멈춘다.
  `--include-mic`이 없으면 DEMO 모드(누르고 말하기) 회기만 지운다. 시연은 마이크로 하므로 붙인다. 시연 전용 샘플 아동의 오늘 기록만 지우며, 임상 검증한 기록이 있으면 거부한다.

## 2. 시연 순서 (약 10~12분)

| 순서 | 누르는 것 | 화면·소리 | 발표자가 말할 것 |
|---|---|---|---|
| 1 | 첫 화면 → `모험 시작하기` → 아이디 `DEMO-CROSSING`, 비밀번호 `speechhero` → `두두 만나기` | 로그인 화면 | 아동용 화면은 글자를 줄이고 두두가 이끈다 |
| 2 | (누르지 않음) | 두두가 점프하며 인사하고 입을 움직이며 말한다 | 첫 말 부담 없이 라포부터 시작한다 |
| 3 | 두두와 대화(마이크) | 목표 소리 /ㅅ/가 든 낱말을 끌어내는 질문 | 대화 맥락 속 목표 낱말 산출 |
| 4 | 빛나는 `대구대 건너기` 버튼(시간이 부족하면 `선생님: 게임으로 넘기기`) | 두두가 게임을 권한다 | 활동 전환을 미리 알려 준다 |
| 5 | `마이크로 시작` | "준비~ 시작!" 뒤 말풍선 카드가 두두 머리 위 동그라미로 다가온다 | 1라운드는 두두가 먼저 들려준다(모방) → 혼자 → 모음 바꾸기 → 낱말 → 섞기 |
| 6 | 카드가 동그라미에 들어오면 말하기 | 성공: 펑(1.5초 안이면 '딱 맞았어!') + 한 줄 점프. 다시: "바람 소리 '스~'를 먼저 내 볼까?" | 점프는 서버 판정이 성공일 때만. 효과는 연출이고 점수가 아니다 |
| 7 | (누르지 않음) | 정문 도착 → "역시 ○○야!" → 마무리 인사 | 아이 화면에는 점수·정확도가 없다 |
| 8 | 치료사 화면: `/therapist/login` → `demo-showcase` / `speechhero` → '최근 세션'의 방금 회기 | 대구대 건너기 관찰 10건(라운드별 점), 음향 근사 안내, 사건 기록 | 판정은 근사값이고, 치료사가 확인·교정한다. 시연 자료는 임상 비교에서 빠진다 |

## 3. 문제가 생기면

| 증상 | 바로 할 일 |
|---|---|
| 마이크로 말해도 잘 못 알아듣는다 | 게임을 `DEMO로 시작(누르고 말하기)`로 다시 시작해 버튼(또는 스페이스)을 누른 채 말한다. 화면에 'DEMO 연습'이 표시되는 것이 정상이다 |
| "서버에 아직 대구대 건너기가 준비되지 않았어요" | 서버가 Codex 데모 버전이 아니다. 서버 버전을 확인한다 |
| 두두 목소리가 여자 목소리·기계음이다 | Edge가 아니거나 인터넷이 끊겼다. 점검 화면에서 목소리를 다시 고른다 |
| 3D 두두 대신 그림이 보인다 | 그래픽 가속이 꺼져 있다(대체 그림은 정상 동작). Edge 설정 → 시스템 및 성능 → '가능한 경우 그래픽 가속 사용'을 켠다 |
| 휴대폰에서 마이크가 안 켜진다 | 주소가 `https://`인지 확인한다(아래 4절) |

## 4. 휴대폰 검사 (임시)

- 휴대폰 마이크는 `https://` 주소에서만 켜진다. 검사할 때 Claude가 PC에서 임시 HTTPS 서버(자체 서명 인증서, 포트 5183)를 띄운다. 인증서와 실행 스크립트는 저장소에 넣지 않는다.
- PC와 휴대폰을 **같은 와이파이**에 연결하고 `https://<PC의 IP>:5183/voice-mic-check.html`, `https://<PC의 IP>:5183/play`를 연다.
- 처음에 "안전하지 않음" 경고가 나온다. Chrome은 `고급 → 계속`, Safari는 `이 웹사이트 방문`을 누른다.
- PC에 Windows 방화벽 창이 뜨면 **개인 네트워크만** 허용한다. 검사가 끝나면 서버를 끈다.
- 휴대폰에는 Edge 남성 음성이 없을 수 있어 기본 한국어 음성으로 나온다.
