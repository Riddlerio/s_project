\# Release PR and README



\## 작업 순서



1\. 변경사항과 현재 브랜치를 확인한다.

2\. 필요한 코드를 구현한다.

3\. 테스트를 실행한다.

4\. README.md를 업데이트한다.

5\. 변경사항을 검토한다.

6\. 커밋하고 현재 작업 브랜치에 push한다.

7\. Pull Request 제목과 본문을 작성한다.



\## README 필수 내용



\- 프로젝트 소개

\- 주요 기능

\- 준비물

\- 설치 방법

\- 실행 방법

\- 사용 예시

\- 테스트 방법

\- 프로젝트 구조

\- 문제 해결 방법



\## README 작성 규칙



\- 초보자가 이해할 수 있는 쉬운 한국어를 사용한다.

\- 명령어는 복사 가능한 코드 블록으로 작성한다.

\- 실제로 확인한 설치·실행 명령만 기록한다.

\- 기존 README 내용을 함부로 삭제하지 않는다.

\- 코드와 README의 내용이 일치하는지 확인한다.



\## 최종 보고



\- 변경 파일

\- README 변경 내용

\- 테스트 결과

\- 커밋 해시

\- Pull Request 주소

\- 남은 문제
