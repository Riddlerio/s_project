# 공개 정적 자산

Vite가 빌드할 때 이 폴더의 파일을 결과물에 그대로 복사합니다. 경로가 `/assets/...`인 파일은 브라우저가 직접 요청합니다.

- `assets/dudu/`: 화면에서 불러오는 두두 3D 모델.
- `assets/voice/dudu/`: 두두 음성 클립과 출처 기록.
- `assets/art/`, `assets/crossing/`: 화면 그림과 건너기 장면 이미지.
- `assets/fonts/`: 웹 글꼴과 라이선스 파일.

파일 이름이나 위치를 바꾸면 소스의 절대 URL, CSS, 음성 테스트도 함께 고쳐야 합니다. 이 README도 배포 결과물에 포함되므로 비밀값이나 내부 자료를 적지 마세요.
