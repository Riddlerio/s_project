# 두두 3D 제작 자료

사용자 결정(2026-10-04): 두두 최종 모델은 **Meshy Pro 웹에서 AI 생성 → Blender 정리·리그 → GLB**로 만든다. 대구대학교 사용 허락은 사용자가 확인했다. 과정 전체는 [로드맵 4절](../../docs/ROADMAP.md)에 있다.

## 입력 이미지 (`meshy_input/`)

| 파일 | 내용 | 쓰는 곳 |
|---|---|---|
| `view_front.png` | 조형 도면 정면(팔 내림 자세), 1024px 흰 배경 | 메인 이미지 |
| `view_side.png` | 같은 도면의 측면. 두두가 **이미지 왼쪽을 바라봄** | 추가 이미지(측면) |
| `view_back.png` | 같은 도면의 후면 | 추가 이미지(후면) |
| `alt_front_plush_target.png` | 털·천 질감 목표 이미지(손을 허리에 얹은 자세) | 질감이 아쉬울 때 메인 이미지로 바꿔 한 번 더 시도 |

도면 원본이 444×450px라서 확대했다. 세부 선이 흐릴 수 있다.

## Meshy에서 할 일 (사용자)

1. Pro 이상 플랜의 **비공개(private)** 상태로 생성한다. 무료 플랜은 결과가 공개된다.
2. Image to 3D의 **Multi-view**를 고른다. 메인에 `view_front.png`, 추가 이미지에 `view_side.png`와 `view_back.png`를 넣는다. 측면은 "캐릭터가 이미지 왼쪽을 바라보는" 방향에 맞는 칸에 넣는다. 결과가 좌우 반대로 보이면 반대 칸으로 다시 해 본다. 자세한 안내는 [Meshy 멀티뷰 도움말](https://help.meshy.ai/en/articles/12634481-how-to-use-multi-view)을 따른다.
3. 선택할 수 있다면 다음으로 설정한다. 자세는 **A-pose**(리깅용), 대칭은 켜기, 텍스처는 켜기(PBR). 같은 입력으로 후보를 2~4개 만든다.
4. 정면·측면·후면이 원화와 가장 닮은 후보 하나를 고른다. 머리가 둥글고 크며, 주둥이가 거의 나오지 않고, 망토가 뒤에서 종 모양이어야 한다. 그다음 **Remesh**(쿼드, 3만 면 안팎)를 거쳐 **Rigging**을 실행한다.
5. 다운로드 파일을 아래 폴더에 넣는다. 이름은 `dudu_meshy_v1.glb`처럼 붙인다. GLB와 FBX(리그 포함)가 둘 다 있으면 둘 다 넣는다.
   - `assets/dudu3d/meshy_output/` ← 이 폴더는 Git에 올리지 않는다(용량).

## 그다음 (Claude)

Blender에서 대칭·감축(휴대폰용 1~2만 삼각형)·UV·줄무늬 텍스처·흉장 교체를 한다. 리그에는 꼬리·귀·망토 본과 표정(깜박임, 입 모양 6개)을 추가한다. 17개 동작 클립을 만든 뒤 GLB(meshopt·KTX2)로 내보내 `public/assets/dudu/`에 둔다. 앱 연결은 GLTFLoader 도입 승인 후 한다.

**전제:** Blender 설치와 작업 파일에 **C 드라이브 여유 공간이 최소 5GB** 필요하다. 2026-10-04 기준 여유 공간은 약 2.2GB다.
