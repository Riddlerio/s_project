# 제작 원본 자산

앱에 바로 배포하지 않는 두두 3D 제작 자료를 보관합니다. 제작 과정과 사용 기록은 [두두 3D README](dudu3d/README.md)에 있습니다.

- `dudu3d/references/`, `dudu3d/meshy_input/`: 캐릭터 참고 그림과 생성 입력 이미지.
- `dudu3d/reference/`: 흉장 제작에 사용한 원본 이미지.
- `dudu3d/tools/`: 모델 변환, 텍스처 보정, 검토 화면 캡처 도구.

브라우저가 쓰는 최종 모델은 `public/assets/dudu/dudu.glb`입니다. 제작 원본과 배포 파일의 경로를 혼동하지 마세요. `dudu3d/meshy_output/`과 `dudu3d/work/`은 Git 제외 대상입니다.
